# System Monitoring Panel UI

A responsive, static IT management and server monitoring dashboard built entirely with HTML, CSS, and Bootstrap 5. 

This project serves as a practical implementation of various modern UI components, focusing on layout structuring and visual feedback elements without the use of JavaScript. It is designed to simulate a real-time system administrator panel where server statuses, resource allocations, and activity logs are monitored.

## 🚀 Key Features

- **Responsive Grid Layout:** Fully responsive design utilizing the Bootstrap grid system, adapting seamlessly from desktop to mobile screens.
- **Visual Feedback Components:** Implementation of Bootstrap **Spinners** and animated **Progress Bars** to simulate system scanning and resource usage (CPU, RAM, Disk).
- **Status Indicators:** Strategic use of Badges and contextual background colors to indicate server health (Active, Critical).
- **Data Presentation:** A clean, easily readable Activity Log utilizing Bootstrap's responsive Table classes with hover states and contextual row coloring.
- **Modern Iconography:** Integrated FontAwesome and Bootstrap Icons for intuitive visual cues next to statuses and warnings.

## 🎯 Learning Focus

The primary goal of this project was to master specific Bootstrap 5 components in isolation. Key takeaways include:
1.  Controlling the alignment and sizing of **Spinners** inside buttons to indicate loading states (e.g., the "System Scanning" button).
2.  Stacking and animating **Progress Bars** to represent server load percentages accurately.
3.  Managing spacing and alignment using Bootstrap's utility classes (Flexbox, padding, margin) instead of writing custom CSS.
